# Security Policy

## Supported Versions

Only the current minor release of Mutant-RL receives security updates.

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| < 0.1.0 | No |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within Mutant-RL, please report it via private disclosure rather than opening a public issue.

### Reporting Procedure
1. Send an email detailing the vulnerability, reproduction steps, and potential impact to `security@mutant-rl.internal` or via GitHub Private Vulnerability Reporting on the repository.
2. Please do not publish proof-of-concept exploits publicly until a fix has been coordinated and released.
3. The maintainers will acknowledge receipt within 48 hours and provide status updates as patches are validated.
